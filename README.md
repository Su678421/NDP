# NDP

## 项目简介

来源是偶然间刷到一个捐赠的视频，评论区大多数人都说不相信现在的慈善组织了，几乎都不捐赠，因为担心这些钱到不了真正需要的人手中。
所以我就想创建一个捐赠网站，可以实现捐赠者与受赠者之间的实时交流，可以互相发送照片、视频等，这样是不是就提高了可信度呢，你可以在捐赠完后直接询问受赠者是否收到了钱。

## 功能详细说明

### 一、普通用户功能

#### 1. 用户注册与登录

##### 捐赠者注册：
- 填写昵称（2-20个字符，支持中文和英文）
- 填写手机号（必须是11位有效手机号，格式验证）
- 设置密码（6-20个字符）
- 可选择默认头像或自定义上传头像
- 系统自动检查用户名唯一性，每个昵称都独一无二

##### 受赠者注册：
- 填写姓名（2-20个字符，支持中文和英文）
- 填写手机号（必须是11位有效手机号，格式验证）
- 填写身份证号（18位，支持末尾X，包含校验码验证）
- 填写快递点信息，如果接受物品捐赠可填。
- 详细描述情况说明（多多益善）
- 可上传图片证明情况（更真实、更容易通过审核）
- 设置密码（6-20个字符）
- 注册后需等待管理员审核，审核期间无法接受捐赠，但可正常登录网站
- 系统自动检查用户名唯一性

##### 登录功能：
- 支持用户名、手机号登录
- 记住登录状态，下次访问无需重复登录
- 登录后显示用户头像和姓名

#### 2. 个人信息管理

##### 个人主页：
- 查看和修改昵称（支持选择一个好听昵称呢）
- 查看用户角色（捐赠者/受赠者）
- 更换头像（支持自定义上传）
- 查看捐赠/受赠记录
- 注销账号（永久删除账户信息），不可恢复

#### 3. 捐赠功能

##### 浏览受赠者：
- 查看所有已通过审核的受赠者列表（）相信审核，会让每一个真正需要帮助的人出现在受赠者列表中
- 查看受赠者头像、姓名、基本情况等
- 可以点击发消息直接与受赠者交流

##### 金钱捐赠（目前未真正实现）：
- 选择受赠者（自动）
- 输入捐赠金额
- 选择支付方式
- 提交捐赠

##### 物品捐赠（目前未真正实现）：
- 选择受赠者
- 填写物品名称
- 描述物品情况
- 确认收货地址
- 提交捐赠

#### 4. 聊天功能

##### 消息功能：
- 捐赠者可点击受赠者（发消息）进行聊天，且聊天记录会出现在自己的消息列表中
- 支持文字、图片、视频交流
- 消息实时同步显示
- 查看聊天记录（仅显示最近三条预览）
- 删除聊天记录，不可恢复，需慎重

##### 消息中心：
- 查看所有对话列表
- 快速进入任意对话
- 删除不需要的对话

#### 5. 问题反馈

##### 提交反馈给管理员：
- 填写姓名
- 填写邮箱
- 详细描述问题或建议
- 提交后自动保存，管理员可查看处理
- 支持未登录用户提交反馈

---

### 二、管理员功能

#### 1. 用户管理

##### 用户列表：
- 查看所有注册用户（包括捐赠者和受赠者）
- 显示用户姓名、角色、状态
- 状态显示：
  - 捐赠者：已认证
  - 受赠者：待审核/已认证/未通过
- 删除用户（除管理员外）
- 支持分页查看

#### 2. 受赠者审核

##### 待审核受赠者：
- 查看所有新注册等待审核的受赠者，只有审核通过后才会出现在受赠者列表中
- 查看受赠者详细信息（姓名、手机号、地址、情况说明）
- 审核后自动给受赠者发送系统消息通知

#### 3. 问题反馈管理

##### 问题反馈列表：
- 查看所有用户提交的问题反馈
- 显示反馈人姓名、邮箱、用户名、问题内容、提交时间、状态
- 状态显示：待处理（红色）/处理中（橙色）/已处理（绿色）

##### 反馈详情：
- 查看反馈的完整内容
- 查看提交时间和用户信息

##### 反馈处理：
- 标记为已处理
- 删除反馈
- 实时更新反馈状态

##当你下载完这个项目时，想在本地部署，你需要做：

### 第一步：安装必需软件

#### 1.1 安装 Node.js

1. 访问 Node.js 官网：<https://nodejs.org/>
2. 下载 LTS 版本（推荐版本 18.x 或更高）
3. 双击安装包，按照提示完成安装
4. **验证安装**：打开命令提示符（CMD），输入：
  
   node -v
 
   应该显示类似 `v18.x.x` 的版本号

#### 1.2 安装 MongoDB

**使用 MongoDB Compass（推荐新手）**

1. 访问：<https://www.mongodb.com/try/download/compass>
2. 下载并安装 MongoDB Compass（包含 MongoDB 服务器）
3. 安装完成后，MongoDB 会自动启动
4. 打开 MongoDB Compass，它会自动连接到本地数据库


**验证 MongoDB 安装**：
打开命令提示符（CMD），输入：


mongod --version


应该显示 MongoDB 版本信息

### 第二步：下载并配置项目

#### 2.1 下载项目

 从 GitHub 下载项目压缩包并解压


#### 2.2 创建环境配置文件

1. 在项目根目录，找到 `.env.example` 文件
2. **复制一份，重命名为** **`.env`**
   - Windows 方法：在文件资源管理器中，右键 → 复制 → 粘贴，重命名为 `.env`
3. 用记事本或 VS Code 打开 `.env` 文件
4. 修改内容如下：
   
# MongoDB 连接字符串
# 本地连接（默认）：
MONGO_URI=mongodb://localhost:27017/ndp-backend

# 端口号（保持默认 3000）
PORT=3000

# JWT 密钥（替换为随机字符串，可以随便写）
JWT_SECRET=mySecretKey123456
```

**说明**：

- `MONGO_URI`：MongoDB 的连接地址，`localhost` 表示本地电脑，`27017` 是默认端口
- `PORT`：服务器运行的端口号
- `JWT_SECRET`：用于加密用户登录令牌，随便写一串字符即可

### 第三步：安装项目依赖

1. 打开命令提示符（CMD）
2. 进入项目目录：
   （先进入项目所在的磁盘）
   cd 你的项目路径\NDP
  
3. 安装依赖：
  
   npm install
   
   这会安装项目所需的所有依赖包，需要等待几分钟

### 第四步：启动数据库

**如果你使用 MongoDB Compass**：

- 打开 MongoDB Compass 软件
- 点击 "New Connection"

1. 在连接框中输入：`mongodb://localhost:27017`
2. 点击 "Connect"
3. **创建一个数据库**：
   - 点击左侧 "Create Database"
   - Database Name：`NDP`
   - Collection Name：`users`（默认集合）
   - 点击 "Create Database"

**如果你使用命令行**：

1. 打开命令提示符（CMD）
2. 启动 MongoDB 服务：
   
   net start MongoDB
   

### 第五步：启动服务器

1. 在命令提示符中，确保在项目目录下
2. 启动服务器：
   
   npm start
   
   或
   
   node server.js
   
3. 如果看到以下信息，说明启动成功：
   ```
   数据库连接成功
   服务器运行在端口 3000
   ```

### 第六步：访问网站

1. 打开浏览器（推荐google浏览器）
2. 在地址栏输入：
  
   http://localhost:3000

3. 应该能看到网站首页
