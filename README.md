# NDP 新捐赠平台

## 项目简介

NDP（New Donation Platform）是一个直接连接捐赠者与受赠者的公益捐赠平台，确保每一份爱心都能精准送达。平台提供用户注册、捐赠管理、即时聊天、问题反馈等完整功能。

## 功能详细说明

### 一、普通用户功能

#### 1. 用户注册与登录

##### 捐赠者注册：
- 填写姓名（2-20个字符，支持中文和英文）
- 填写手机号（必须是11位有效手机号，格式验证）
- 设置密码（6-20个字符）
- 可选择默认头像或自定义上传头像
- 系统自动检查用户名唯一性

##### 受赠者注册：
- 填写姓名（2-20个字符，支持中文和英文）
- 填写手机号（必须是11位有效手机号，格式验证）
- 填写身份证号（18位，支持末尾X，包含校验码验证）
- 填写快递点信息
- 详细描述情况说明（至少10个字符）
- 可上传图片证明情况（可选）
- 设置密码（6-20个字符）
- 注册后需等待管理员审核，审核期间无法接受捐赠
- 系统自动检查用户名唯一性

##### 登录功能：
- 支持用户名、手机号或邮箱登录
- 记住登录状态，下次访问无需重复登录
- 登录后显示用户头像和姓名

#### 2. 个人信息管理

##### 个人主页：
- 查看和修改昵称
- 查看用户角色（捐赠者/受赠者）
- 更换头像（支持自定义上传）
- 查看捐赠/受赠记录
- 注销账号（永久删除账户信息）

#### 3. 捐赠功能

##### 浏览受赠者：
- 查看所有已通过审核的受赠者列表
- 查看受赠者头像、姓名、需要帮助内容
- 查看详细情况说明

##### 金钱捐赠：
- 选择受赠者
- 输入捐赠金额
- 选择支付方式
- 提交捐赠

##### 物品捐赠：
- 选择受赠者
- 填写物品名称
- 描述物品情况
- 确认收货地址
- 提交捐赠

#### 4. 聊天功能

##### 消息功能：
- 与捐赠者/受赠者一对一聊天
- 发送文字消息
- 发送图片消息（支持图片上传和预览）
- 发送视频消息（支持视频上传和播放）
- 消息实时同步显示
- 查看聊天记录（仅显示最近三条预览）
- 删除聊天记录

##### 消息中心：
- 查看所有对话列表
- 快速进入任意对话
- 删除不需要的对话

#### 5. 问题反馈

##### 提交反馈：
- 填写姓名
- 填写邮箱
- 详细描述问题或建议
- 提交后自动保存，管理员可查看处理
- 支持未登录用户提交反馈

---

### 二、管理员功能

#### 1. 用户管理

##### 用户列表：
- 查看所有注册用户（包括捐赠者和受赠者）
- 显示用户姓名、角色、状态
- 状态显示：
  - 捐赠者：已认证
  - 受赠者：待审核/已认证/未通过
- 删除用户（除管理员外）
- 支持分页查看

#### 2. 受赠者审核

##### 待审核受赠者：
- 查看所有新注册等待审核的受赠者
- 查看受赠者详细信息（姓名、手机号、地址、情况说明）
- 通过审核：批准后受赠者可以接受捐赠
- 拒绝审核：拒绝后受赠者无法接受捐赠
- 审核后自动给受赠者发送系统消息通知

#### 3. 问题反馈管理

##### 问题反馈列表：
- 查看所有用户提交的问题反馈
- 显示反馈人姓名、邮箱、用户名、问题内容、提交时间、状态
- 状态显示：待处理（红色）/处理中（橙色）/已处理（绿色）

##### 反馈详情：
- 查看反馈的完整内容
- 查看提交时间和用户信息

##### 反馈处理：
- 标记为已处理
- 删除反馈
- 实时更新反馈状态

---

### 三、系统功能

#### 1. 本地存储
- 使用 LocalStorage 存储聊天记录
- 使用 LocalStorage 存储用户数据
- 使用 LocalStorage 存储反馈数据
- 使用 LocalStorage 存储头像信息

#### 2. 数据验证
- 手机号格式验证（11位，以1开头）
- 身份证号格式验证（18位，支持X）
- 密码强度验证（6-20位）
- 姓名格式验证（2-20位）
- 用户名唯一性验证

#### 3. 响应式设计
- 支持桌面端访问
- 支持移动端访问
- 自适应屏幕尺寸

## 技术栈

### 前端
- HTML5 + CSS3
- JavaScript (原生)
- LocalStorage (本地存储)

### 后端
- Node.js + Express
- MongoDB (数据库)
- JWT (身份验证)
- Socket.io (实时通信)

### 依赖库
- bcrypt (密码加密)
- cors (跨域支持)
- dotenv (环境变量管理)
- mongoose (MongoDB ORM)
- multer (文件上传)

## 快速开始

### 本地运行步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/your-username/ndp-donation-platform.git
   cd ndp-donation-platform
   ```

2. **安装依赖**
   ```bash
   cd ndp-backend
   npm install
   ```

3. **配置环境变量**
   在 `ndp-backend` 目录创建 `.env` 文件：
   ```
   MONGO_URI=mongodb://localhost:27017/ndp-backend
   JWT_SECRET=your-secret-key-here-change-in-production
   PORT=3000
   ```

4. **启动 MongoDB**
   - 启动 MongoDB 服务
   - 使用 MongoDB Compass 连接本地数据库

5. **启动服务器**
   ```bash
   npm start
   ```
   或者
   ```bash
   node server.js
   ```

6. **访问网站**
   打开浏览器访问：`http://localhost:3000`

## 部署说明

### 本地部署（推荐用于测试）

1. 确保 Node.js 和 MongoDB 已安装
2. 按照上面的"快速开始"步骤操作
3. 使用 ngrok 等工具进行内网穿透，让其他人访问

### 云服务器部署（推荐用于正式使用）

1. 购买云服务器（阿里云、腾讯云等）
2. 安装 Node.js 和 MongoDB
3. 上传代码到服务器
4. 配置环境变量
5. 使用 PM2 等工具管理进程
6. 配置防火墙规则开放端口
